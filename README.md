# Expense Tracker

A Flutter mobile application for recording, organizing, and reviewing personal expenses.

## Overview

Expense Tracker is a mobile-first application built with Flutter to practice cross-platform UI development and structured expense management.

The goal is to make it easy to record day-to-day spending and understand where money is being allocated.

## Features

- Add new expenses
- View recorded transactions
- Organize spending by category
- Track expense amounts over time
- Mobile-friendly Flutter UI

## Tech Stack

- Flutter
- Dart
- Android

## Getting Started

### Prerequisites

Install:

- Flutter SDK
- Dart SDK
- Android Studio or another supported Flutter development environment

### Installation

```bash
git clone https://github.com/sanjayt2706/expensetracker.git
cd expensetracker
flutter pub get
flutter run
```
